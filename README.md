## What DeskHaus Is

DeskHaus gathers common office work into a single compact surface. Draft and format documents, build tables that can calculate, pull in spreadsheet data, and refine images with a layer-oriented editor—without juggling separate apps for each task.

Built as an HTML and JavaScript application for browser and desktop use, it ships as a single file you can run offline. There is no server dependency and no traditional installer, which keeps it handy for short document, table, and image jobs on supported Windows setups.
